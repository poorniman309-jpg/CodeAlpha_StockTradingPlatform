# Stock Trading Platform

A Java-based stock trading simulator developed as part of the CodeAlpha Java Programming Internship.

Features

- Simulated stock market prices
- Buy and sell stocks
- Portfolio management
- Profit and loss tracking
- Stock watchlist
- Transaction history
- Save and load trading data
- Export transactions to CSV
- Dark-themed graphical user interface

Technologies Used

- Java
- Java Swing
- Object Serialization
- CSV File Handling

How to Run

1. Install the Java Development Kit (JDK).

2. Open the project folder in VS Code.

3. Open the terminal in the project folder.

4. Compile the program:

   javac StockTradingPlatform.java

5. Run the program:

   java StockTradingPlatform

Disclaimer

This project is an educational stock trading simulator. It does not perform real stock market transactions.
